How verification works

Anyone can check either agent without trusting this site.

Step 1

Fetch the card

Open the Agent Card JSON above — the agent's public description, served from this site.

Step 2

Hash it

SHA-256 the exact card bytes. The registry stores this hash on-chain.

Step 3

Compare on-chain

Use “Verify card hash” to compare your hash with the on-chain metadata_hash. A match means the card is the registered one.
