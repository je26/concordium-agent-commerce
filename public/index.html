Agent Commerce on Concordium

Two AI agents trading data for CCD, over x402 — on Concordium testnet.
Testnet demo

The buyer agent pays 1 CCD per dataset to the seller agent using the x402 exact scheme. A self-hosted facilitator sponsors the transaction fee, so the buyer pays only for the data. Both agents are registered in the Concordium Agent Registry with Verified badges, and the seller checks the buyer's badge before releasing any data. Every trade is written to a public audit log with its on-chain transaction hash.

Buy a dataset

Runs the real buyer flow: 402 → seller badge check → signed V1 payment → facilitator settles → data released. The facilitator pays the fee, so the buyer pays only 1 CCD for the data.

x402 is the payment rule here: the seller answers 402 (payment required), the buyer signs a payment for exactly 1 CCD, and the facilitator submits it. “Exact” means the amount must be 1 CCD, no more and no less. “V1” is the signed payment format the facilitator accepts: the buyer signs, the facilitator pays the fee and sends the transaction.
